# Cafe KATTO
 
Website statis untuk **Cafe KATTO**, sebuah maid cafe bertema Jepang. Website ini memperkenalkan cafe, suasananya, menu yang ditawarkan, serta informasi kontak untuk pengunjung.
 
Project ini dibuat sebagai tugas akhir **Weekly Meet Catalyst – Build Together: Collaborative Mini Project**.

## Tujuan / Latar Belakang
 
Cafe KATTO adalah website bertema bisnis (company profile cafe) yang bertujuan:
 
- Memperkenalkan konsep Cafe KATTO sebagai maid cafe kepada calon pengunjung.
- Menampilkan menu makanan dan minuman beserta tampilannya agar pengunjung mudah memilih.
- Menyediakan informasi kontak dan media sosial sehingga pengunjung mudah menghubungi atau mengunjungi cafe.
Selain itu, project ini menjadi latihan bagi kami untuk bekerja dalam tim menggunakan Git dan GitHub: membagi task lewat Issues, bekerja di branch masing-masing, membuat Pull Request, dan saling mereview.

## Fitur / Section
 
- **Navbar** – menu navigasi (Menu, Story, Staff & Cast, Visit) yang mengarah ke tiap section.
- **Home / Hero** – sambutan "Welcome Home, Master & Princess!", deskripsi singkat, ilustrasi, dan tombol *Explore Our Menu*.
- **Menu (Today's Favorites)** – 10 menu dalam bentuk kartu berisi foto, nama, deskripsi, dan harga, dikelompokkan menjadi Food & Mains, Sweet Desserts, dan Specialty Coffee, dengan tombol filter kategori.
- **Staff & Cast (Meet Our Maids)** – profil anggota tim pengembang yang dibuat bertema maid cafe.
- **Visit** – alamat, jam operasional, serta kontak lewat WhatsApp dan Instagram.
- **Footer** – tautan navigasi dan hak cipta.

Cara Menjalankan Secara Lokal
Clone repository ini:
bash
   git clone https://github.com/yauraa/Cafe-KATTO.git
Masuk ke folder project:
bash
   cd Cafe-KATTO
Buka file index.html langsung di browser (klik dua kali, atau klik kanan lalu Open with browser).
Alternatif: jika memakai VS Code, install ekstensi Live Server, lalu klik kanan index.html dan pilih Open with Live Server.

Tidak diperlukan instalasi tambahan karena website ini bersifat statis.
